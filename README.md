Every ![dataset](datasets) contains a script to download the data, along with a readme that describes where it came from. 
All plots are generated by ![scripts](scripts) that access that data and generate a bunch of ![plots](docs/assets) automatically.

To regenerate the plots on your end:
- navigate to this folder
- julia --project=. main.jl 

The script will first go through every folder in datasets and if the data is missing, it will redownload it (we store the data locally as to not get rate limited). Then, it will regenerate all plots.
